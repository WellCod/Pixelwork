# Prompts de fase

Use no Claude Code, um por vez, na ordem. Cada fase termina com algo demonstrável e com uma parada
para revisão. Não comece a fase seguinte sem revisar a anterior.

Antes da fase 0: coloque `CLAUDE.md` na raiz do repositório e `docs/` ao lado.

Linha de corte se o tempo apertar: fases 0 a 4, mais README e números de carga da fase 8.
